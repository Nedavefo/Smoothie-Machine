# Smoothie Machine

An ordering form for custom smoothies, built to practice object-oriented JavaScript.

**Live demo:** https://nedavefo.github.io/Smoothie-Machine/

## How it works

- The user picks a size, one or more fruits, a base and optional add-ins
- The form values are used to create a `Smoothie` instance (ES6 `class`)
- `Smoothie.describe()` renders the order summary on the page

Plain HTML, CSS and vanilla JavaScript, with no dependencies.
